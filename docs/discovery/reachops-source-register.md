# ReachOps Discovery Source Register

Research snapshot: **2026-08-10**. Sources were accessed on that date unless otherwise noted. Primary vendor and platform documentation was preferred. Pricing is a point-in-time observation, not a quote; vendors change packaging, currencies, taxes, limits, and discounts.

## Source quality legend

- **Primary technical** — platform owner documentation; authoritative for API behavior, permissions, and policy.
- **Primary commercial** — vendor product or pricing page; authoritative for current positioning and published packaging, but naturally promotional.
- **Secondary** — used only for context when primary material did not expose a detail. No core feasibility conclusion depends only on a secondary source.

## Research cautions

1. Meta documentation is frequently rendered dynamically and is not consistently indexable. The Meta-owned Postman collection is treated as primary, but permissions must be reconfirmed in the Meta App Dashboard before implementation.
2. LinkedIn Marketing APIs are versioned monthly and older versions sunset. Implementation must target a then-supported version, not copy the version shown in this report.
3. Google Business Profile combines several APIs and unusually restrictive policy language. Legal/policy review is required before retaining or aggregating GBP content beyond the permitted use.
4. “API exists” does not mean “portfolio app will be approved.” The feasibility matrix distinguishes technical capability from realistic access.
5. No private vendor demos, trial accounts, or API applications were completed during this research phase. Conclusions are based on public documentation, not fabricated access.
